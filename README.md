## How to Use These Notes

1. Follow the modules in order so that each topic builds on the previous one.
2. Read each question and try to answer it aloud before reading the provided answer.
3. Study the root-level explanation and understand why the Java feature exists.
4. Write and run the small code examples instead of only reading them.
5. Practice the follow-up and counter-questions as if you were in a real interview.
6. Finish with the Interview Grill and Final Preparation modules.

Most completed modules follow an interview-friendly structure:

- Short interview answer
- Deep or root-level explanation
- Code examples
- Common fresher mistakes
- Follow-up and tricky questions
- Related concepts to revise
